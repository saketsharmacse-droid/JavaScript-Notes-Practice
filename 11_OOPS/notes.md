# OOP
- OOP is object oriented programming, is a programming paradigm that follows the structure or the way of writing the code.
-Object is actually a collection of properties and methods.
- Eg toLowerCase, Promises, etc.

## Why use OOP?
- code bahut mess up ho rha tha, spaghatti code krke ek concept hota hai, codes ka chunk wapis se reuse nhi ho paa rha tha.
- oop ke bina bhi kaam same chlra tha, but readibility aur implementation issues ke kaaran oops use kiya gya.
- bahut saare features aur bhi behtar use krr paaye dur to oop, like services in js.
